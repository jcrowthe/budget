# Register selection, action bar and flags: polish list (EXF-520, EXF-522)

Design: [register-bulk-design.md](register-bulk-design.md). Measured by the Designer against the source, dark theme.

- P1 [applied] Flag glyph: a pennant with no pole (24 x 15 drawing, V notch on the right, outline and filled), drawn by us in `register/icons.tsx`. It is shown at 20 x 12.5 so the cell button is 36px wide with `padding: 0 var(--space-2)` and no fixed width (the source's button measures 35.6 x 22). The column header uses the filled one; its colour stays `--register-icon-muted`.
- P2 [applied] Bar icons (Categorize, Flag, More) 12 x 12 (the close × stays 8 x 8); `.action-bar-uncheck` margin 0; the bar's line-height 16.8px.
- P3 [applied] The flag menu's full-width rule is now `.bulk-popover hr.flags-hr`, so the More, Move and Categorize lists keep `margin: 4px 12px`. `.bulk-popover-body` padding is 0; the flag menu alone keeps 1px (`Popover` `bodyClass="is-flags"`).
- P4 [applied] Entry icons `--labelTertiary`; disabled entry icons `--register-icon-disabled: #56596c` (new property); key cap background `rgba(114,116,132,.18)` (via `--register-keycap-bg`), text `--register-icon-muted`, white on hover of an enabled entry; disabled rows `padding-block: 6px`; icon gap 11.5px. The flag menu's key caps keep `--labelSecondary` (not measured).
- P5 [scoped] Memo dialog: `.bulk-input` margin 8px 0, the label's margin 0, and a disabled Update in `--menuHover` / `--labelTertiary` at opacity 1, all under `.bulk-dialog` (global.css is in the shell and not touched).
- P6 [applied] Flag menu rows and the Edit Flags footer `margin: 16px`. The flag cell's menu sits 5px closer to its cell (`Popover` `belowTrim`), which puts it about 2.5px below the cell with the arrow overlapping it. The bar's Flag button menu is unchanged. Edit Flags stays drawn disabled (EXF-480).
- P7 [applied] A shortcut tooltip on Approve, Reject, Categorize, Flag and Clear, built on `account/Tooltip.tsx` with new `placement="above"` and `align="center"` variants and the new `--account-tooltip-shortcut-bg` (#3c3e53) property next to `--account-tooltip-label` / `--account-tooltip-shadow`. It shows with no delay; the key caps are `rgba(255,255,255,.15)`, 20 x 20 minimum; "then" has no cap. The native `title` of those five buttons is gone (the tooltip replaces it); the "Deselect all" title on the × button stays, as the source shows no tooltip there.
- P8 [applied] With several rows, Categorize opens a 232px menu like More: one entry per group ("Inflow" first) with a 12px chevron; hovering or clicking a group marks it active and opens a 256px submenu to its right (`Popover` `dx={-5}`, `is-submenu` shadow `0 0 16px rgba(0,0,0,.1)`) with that group's categories, no balances. A pick sends `categorize` as before. The one-row path is unchanged.
